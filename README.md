## iCable 双ISP 原生住宅IP 到底解决什么问题

所谓双ISP，通常指IP登记信息里的运营商和ASN归属都落在本地宽带运营商一侧，而不是数据中心段。配合“原生住宅静态IP”，意思是这个IP从登记属性上看更像一条香港本地家庭宽带，而不是一台机房里的服务器。对于会看IP属性的平台风控来说，这是机房IP和住宅IP之间最实质的差别。IP是静态的，不会每次重拨就换。
